## 기록 원칙

- 날짜, 대상 모델, 커널·드라이버·펌웨어·도구 버전과 확인 명령을 기록합니다.
- 실제 관측값, 해석, 미확정 원인, 조치 계획을 구분합니다.
- 장치 번호는 재부팅·이전 후 달라질 수 있으므로 내부 시리얼 매핑을 유지하고, 공개 문서에는 카드 별칭을 사용합니다.
- 공개 저장소에는 실제 시리얼·UUID, 인증 정보, 내부 접속 경로를 기록하지 않습니다.
- 서버 설정 변경과 부하 테스트는 작업 범위 및 유휴 시간을 확보한 후 별도 기록합니다.
