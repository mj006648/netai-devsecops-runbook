# 서버 하드웨어를 연결해서 이해하기 — A7 GPU·NPU 노드로 배우는 교재

작성·공식 자료 확인 기준: **2026-09-21**. 00장은 전기·비트·논리회로를 처음 배우는 독자부터 시작한다. 이후 CPU, RAM, PCIe, GPU/NPU, NIC, 스토리지의 관계를 운영·설계 관점으로 확장한다. 회로 설계나 반도체 제조 지식은 전제하지 않는다. 기초·계산·추적 설명 보강: **2026-09-22**.

이 교재의 목표는 부품 이름을 외우는 데 있지 않다. 서버의 블록도와 실제 조회 결과를 보고 **데이터가 어디에 저장되고, 어느 경로를 지나며, 무엇을 공유하고, 어느 조건에서 느려지는지** 설명할 수 있게 하는 것이다. 새 GPU나 NIC를 구매할 때도 물리 공간, 연결 대역폭, 소프트웨어 지원, 전원·냉각을 함께 판단할 수 있어야 한다.

[네 교재 통합 학습 순서](../../../learning/README.md) · [운영체제·커널](../../../linux/learning/linux-kernel/README.md) · [네트워크·eBPF](../../../kubernetes/networking/networking-foundations/README.md) · [파일·데이터 시스템](../../../kubernetes/storage/data-systems-foundations/README.md)

처음에는 정확한 이름을 외우기보다 **왜 필요한가 → 실제로 무엇이 움직이는가 → 숫자로 계산할 수 있는가 → 어느 조건에서 설명이 달라지는가** 순서로 읽는다. 고급 제품 사양과 A7 사례는 기본 원리를 배운 뒤 확인한다.

## 읽고 나면 답할 수 있어야 하는 질문

- CPU 두 개와 NUMA 두 개는 언제 같고 언제 다른가? RAM 128GB가 있어도 왜 채널 수를 봐야 하는가?
- x16 슬롯 네 개가 있으면 CPU까지 네 장 모두 x16 속도로 동시에 전송할 수 있는가?
- NVMe와 GPU가 같은 PCIe 스위치에 연결되면 무조건 잘못된 구성인가?
- SSD, M.2, NVMe, RAID, 파일시스템, `/data`는 각각 어느 계층의 이름인가?
- RAID 카드를 꽂는 것과 RAID1을 설정하는 것은 왜 다른가?
- 100G NIC에 PCIe Gen4 x8이면 충분한가? 두 포트를 동시에 쓰면 계산이 어떻게 달라지는가?
- GPU의 GDDR/HBM, 호스트 DDR, SRAM은 왜 용량을 한 덩어리로 더할 수 없는가?
- PCIe P2P, RDMA, NVLink, UALink, CXL은 각각 무엇을 해결하는가?
- NVLink가 빠르다는 자료를 보고 RTX PRO 카드에 NVLink 케이블을 주문해도 되는가?
- 빈 슬롯이 보여도 카드 장착을 확정할 수 없는 이유는 무엇인가?

## 공부 방법

1. 각 장의 그림을 본 뒤, 글을 가리고 연결 구조를 다시 그린다.
2. 계산에는 단위를 붙인다. `100G`, `x16`, `1.8TB/s`만 적힌 숫자는 비교에 충분하지 않다.
3. 명령 출력의 필드가 무엇을 증명하는지와 무엇을 증명하지 못하는지 설명한다.
4. 장 끝의 문제를 먼저 풀고 해설을 읽는다. 장치 상태와 성능을 혼동하지 않았는지 점검한다.
5. 마지막에 10장의 노드 설계 문제를 풀고, 부족한 정보 목록을 직접 작성한다.

## 실제 관측·예제·제품 사양을 구분하는 규칙

| 표시 | 의미 |
|---|---|
| A7 실측 | 2026-09-21 작업일지에서 확인한 값. 이후 장치 이동이나 설정 변경으로 달라질 수 있음 |
| 계산 예제 | 개념 설명을 위해 정한 수치. 현재 성능 측정이나 구매 승인 값이 아님 |
| 공식 제품 사양 | 지정된 제품·버전에 대한 제조사 수치. 모든 제품이나 실제 납품 옵션에 자동 적용되지 않음 |
| 표준·발표 | 규격이나 제품 계획이 공개됐다는 뜻. 현장 호환성과 공급 가능성은 별도 확인 |

실제 구성의 기준 문서는 [A7 증설 검토·RAID 실측](../../npu/a7-expansion-plan-2026-09-21.md)와 [슬롯·NUMA·binning 작업일지](../../npu/a7-rngd-slot-numa-binning-2026-09-21.md)다. 교재가 작업일지의 미완료 항목을 완료로 바꾸지는 않는다.

이번 교재 작성은 문서 작업이다. 교재에 실습 명령이 있어도 이번에 새로 서버에서 실행했다는 뜻이 아니다. 09장은 조회만 제공하며 벤치마크·장치 이동·BIOS·ACS·네트워크·RAID 구성 변경을 포함하지 않는다. 내부 IP, 계정, 실제 장치 시리얼은 공개하지 않는다.

## 이 교재의 범위

다룰 범위는 **PCIe 기반 GPU/NPU 서버를 설치·확장·운영하는 데 필요한 시스템 수준의 하드웨어 이해**다. CPU 마이크로아키텍처 설계, 고속 신호 회로 설계, 건물 전기 공사, 특정 제품의 현장 정비 매뉴얼을 대체하지는 않는다. 대신 어떤 작업에 OEM 매뉴얼이나 전문 설계가 필요한지를 구분할 수 있도록 설명한다.

최신 기술 장은 2026-09-21 확인본이다. `latest` 공식 문서는 내용이 바뀔 수 있으므로 구매·업그레이드 시 해당 제품 P/N과 사용 버전으로 다시 확인한다. 수치가 달라지면 단순히 큰 숫자를 채택하지 말고 방향, 집계 범위, 프로토콜, 제품 버전부터 대조한다.
