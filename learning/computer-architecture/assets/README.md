# 컴퓨터 구조 그림 자료

이 디렉터리의 SVG는 특정 CPU 제품의 내부 배치를 복제한 도면이 아니라, 본문에서 다루는 공통 원리를 한눈에 추적하기 위한 교육용 모형입니다.

모든 그림은 SVG의 `<title>`과 `<desc>`를 포함하며, 본문에서는 대체 텍스트가 있는 이미지 링크로 사용합니다.

| 파일 | 설명 | 연결 장 |
|---|---|---|
| `execution-map.svg` | 프로그램부터 명령어 실행, 메모리, 장치까지 이어지는 전체 지도 | 00장 |
| `pipeline.svg` | 5단계 파이프라인과 단계 사이 래치 | 04장 |
| `cache-address.svg` | 주소를 태그·세트 인덱스·블록 오프셋으로 나누는 과정 | 06장 |
| `coherence.svg` | 두 코어 캐시와 공유 메모리 사이의 일관성 메시지 | 07장 |
| `page-walk.svg` | 가상 주소, TLB, 페이지 테이블, 물리 주소의 관계 | 09장 |
| `roofline.svg` | 연산 집약도에 따른 메모리 한계와 계산 한계 | 10장 |

그림의 상자와 화살표는 설명 순서를 나타냅니다. 실제 프로세서에서는 단계가 합쳐지거나 더 잘게 나뉠 수 있고, 캐시 계층·페이지 테이블 단계·일관성 프로토콜도 ISA, 운영체제, 제조사 구현에 따라 달라집니다.
