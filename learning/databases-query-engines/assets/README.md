# 그림 자료

본문의 처리 흐름을 확대해서 볼 수 있는 SVG 자료다. 모든 그림은 교육용 단순화이며 화살표는 입력에서 결과로 진행하는 방향을 나타낸다.

- `database-query-map.svg`: SQL에서 페이지·WAL까지 전체 지도
- `page-buffer-path.svg`: 페이지 읽기와 버퍼 풀 경로
- `query-plan-tree.svg`: 필터와 해시 조인의 실행 트리
- `mvcc-visibility.svg`: 두 튜플 버전과 스냅샷 판정
- `wal-recovery.svg`: WAL 선행 기록과 복구
- `columnar-vectorized.svg`: 열 저장과 벡터 연산
