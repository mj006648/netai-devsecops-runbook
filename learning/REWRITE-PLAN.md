# 학습 교재 개편 기준 — 2026-10-07

## 목표와 범위

컴퓨터 용어를 처음 만나는 독자가 용어의 뜻과 실제 작동을 연결하고, 계산과 작은 실습으로 설명을 확인할 수 있게 한다. 통합 안내와 그 안내가 연결하는 서버 하드웨어·Linux·네트워크·데이터 시스템·AI 인프라의 **59개 장**, 분야별 목차·용어사전·실습 안내가 대상이다. 운영 장애 기록의 사실이나 실제 서버 설정은 변경하지 않는다.

## 확인한 문제와 수정 방향

1. **출발점:** `A7` 같은 연구실 고유명이 기술명처럼 먼저 등장한다. 장비의 정체를 설명하고 일반 원리 뒤의 사례로 옮긴다.
2. **설명 깊이:** 용어 한 줄로 끝나는 부분과 이미 계산·추적이 있는 부분의 깊이가 다르다. 이름의 정의에 더해 위치, 제어 주체, 시간 순서, 공유 자원, 실패 조건을 설명한다.
3. **선수지식:** 개념을 모르면 다른 장으로 이동해야 하는 짧은 연결 문서가 있다. 기본 설명을 해당 장에서도 제공하고 더 깊은 연결을 안내한다.
4. **시각 자료:** 구조를 상상해야 하는 부분에 실제 SVG 설명도와 Mermaid 경로·순서도를 넣는다. 그림의 각 요소와 화살표를 본문에서 설명한다.
5. **학습 확인:** 문제에는 답과 이유를 붙이고 실습에는 실행 위치, 전제, 예상 관찰, 결과의 의미를 붙인다.

## 편집 순서와 책임

기존 내용을 읽고 분야별 계획을 세운 뒤, 다섯 교재를 독립 범위로 편집한다. CPU·DRAM 및 GPU 실행은 별도 집중 편집한다. 통합 담당자는 목차·입문장·출처·교재 간 연결을 정리하고 편집 이후 전체 링크, 문서 구조, 그림, 기존 예제를 검증한다. 작성 담당자와 최종 검토 담당자의 역할을 구별한다.

## 보존할 계약

- 기존 파일 경로와 유용한 장 제목·앵커를 보존한다.
- 기존 실행 예제와 정확한 기술 설명, 공식 출처를 보존한다. 새 실습을 추가할 때는 작은 로컬 모형임을 명시한다.
- 제품 사양, 실제 관측, 계산 가정, 아직 검증하지 않은 주장을 구별한다.
- DDR 메모리의 rank, 분산 실행의 rank, GPU shared-memory bank의 서로 다른 뜻을 설명한다.
- 새로운 패키지나 서버·클러스터 변경을 요구하지 않는다.
- 오래된 검증 기록은 당시 기록으로 남기고 이번 실행 결과는 날짜를 구분해 기록한다.

## 완료 조건

59개 장 전부에 주제별 진입 설명과 시각적 동작 설명이 있다. 핵심 구조에는 재사용 가능한 SVG 자산과 대체 텍스트·설명 문장이 연결된다. 학습 경로 안의 파일·앵커·이미지 링크와 문서 구문을 확인한다. 기존 AI 모형 검사, 파일 I/O 단위 테스트 및 작은 실제 파일 실습을 새로 실행한다. 검증하지 못한 렌더링·실장비 성능은 기록에서 명시한다.
