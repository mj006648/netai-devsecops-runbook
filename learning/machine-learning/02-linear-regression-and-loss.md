# 02. 선형회귀와 손실

[← 이전](01-vectors-matrices-and-probability.md) · [목차](README.md) · [다음 →](03-gradients-and-optimization.md)

회귀는 연속적인 숫자를 예측하는 문제다.

선형회귀는 입력의 가중합으로 예측을 만든다.

손실은 예측과 정답의 차이를 학습 가능한 숫자로 바꾼다.

## 이 장의 목표

1. 새 용어와 수학 기호를 말로 설명한다.
2. 입력이 중간 숫자를 거쳐 결과가 되는 과정을 계산한다.
3. 계산 모형과 실제 성능 주장을 구분한다.

![02. 선형회귀와 손실 도식](assets/regression-gradient.svg)

## 기본 단어와 기호

**regression**는 연속값 예측이다.

**linear model**는 입력의 가중합 모델이다.

**weight**는 feature 영향의 크기와 방향이다.

**bias**는 입력이 0일 때 더하는 기준값이다.

**prediction**는 모델 출력 ŷ이다.

**target**는 실제 정답 y이다.

**error**는 예측-정답이다.

**squared error**는 오차 제곱이다.

**MSE**는 제곱오차의 평균이다.

**residual**는 관측값과 fitted 값의 차이이다.

**fit**는 data에 parameter를 맞추는 일이다.

**unit**는 숫자가 나타내는 측정 단위이다.

기호를 읽을 때 이름, shape, 단위, 생성 주체를 함께 적는다.

## 왜 필요한가

- 예측 오차의 방향과 크기를 알아야 parameter를 고칠 수 있다.
- 제곱은 양·음 오차가 상쇄되는 것을 막고 큰 오차를 더 크게 벌준다.
- 손실 선택은 어떤 오류를 중요하게 보는지 정한다.
- 좋은 training fit과 새 data generalization은 다르다.

## 입력에서 결과까지

1. 입력 x와 target y를 읽는다.
2. 모델이 ŷ=wx+b를 계산한다.
3. Evaluator가 error=ŷ-y를 계산한다.
4. Loss 함수가 0.5×error²를 만든다.
5. Gradient 계산이 w와 b의 민감도를 구한다.
6. Optimizer가 learning rate만큼 parameter를 바꾼다.
7. 새 parameter로 다시 예측한다.
8. 독립 data에서 오차를 평가한다.

```mermaid
flowchart LR
    X[관측 입력 x] --> P[예측값 wx+b]
    W[가중치 w와 편향 b] --> P
    P --> R[잔차: 정답-예측]
    Y[정답 y] --> R
    R --> L[잔차 제곱의 평균 MSE]
    L --> G[가중치별 변화 방향]
```

## 작은 숫자로 한 번 계산하기

x=2, y=5, w=1, b=0이다.

예측 ŷ=1×2+0=2다.

Error=2-5=-3이다.

Loss=0.5×(-3)²=4.5다.

w gradient=error×x=-3×2=-6이다.

b gradient=error=-3이다.

학습률 0.1이면 새 w=1-0.1×(-6)=1.6이다.

새 b=0-0.1×(-3)=0.3이다.

새 예측=1.6×2+0.3=3.5다.

새 loss=0.5×(3.5-5)²=1.125다.

| 구분 | 값 또는 책임 |
|---|---|
| 입력 | x=2 |
| 정답 | y=5 |
| 처음 loss | 4.5 |
| 한 step 뒤 loss | 1.125 |

## 여러 관측값에서 평균제곱오차 계산하기

한 점의 손실만 줄이면 그 점에는 가까워져도 다른 점에서 멀어질 수 있다.

따라서 여러 관측을 함께 계산해 보자.

입력은 `x=[1,2,3]`, 정답은 `y=[2,4,5]`다.

현재 가중치 `w=1`, 편향 `b=1`이다.

예측은 다음과 같다.

```text
x=1: 예측=1×1+1=2, 정답=2, 예측-정답=0
x=2: 예측=1×2+1=3, 정답=4, 예측-정답=-1
x=3: 예측=1×3+1=4, 정답=5, 예측-정답=-1
```

제곱오차는 `[0,1,1]`이다.

평균제곱오차는 `(0+1+1)/3=2/3≈0.667`이다.

`0.5×평균제곱오차`를 손실로 정의하면 약 `0.333`이다.

앞의 `0.5`는 최적 위치를 바꾸지 않는다.

미분할 때 제곱의 2와 약분되어 식을 간단하게 만들기 위해 자주 사용한다.

문서와 code가 MSE를 쓰는지 half-MSE를 쓰는지 확인해야 숫자를 직접 비교할 수 있다.

정답 단위가 섭씨 온도라면 잔차 단위는 `°C`, 제곱오차 단위는 `°C²`다.

제곱 손실 값 자체를 원래 온도 오차처럼 읽으면 안 된다.

## 왜 가중치 기울기가 오차 곱하기 입력인가

예측식 `ŷ=wx+b`에서 w를 아주 조금 `Δw`만큼 늘리면 예측은 `x×Δw`만큼 변한다.

입력 x가 2이면 w를 0.01 늘릴 때 예측은 0.02 늘어난다.

Half squared loss는 `0.5(ŷ-y)²`다.

예측이 조금 변할 때 손실 변화율은 `ŷ-y`, 즉 예측-정답 오차다.

두 변화율을 연쇄법칙으로 곱하면 다음과 같다.

```text
dL/dw = dL/dŷ × dŷ/dw
      = (ŷ-y) × x
```

앞 예제에서 오차가 -3이고 x=2이므로 기울기는 -6이다.

음수 기울기는 w를 조금 키우면 이 지점의 손실이 줄어드는 방향임을 뜻한다.

## 한 점의 손실만 줄이는 반례

두 관측 `(x=1,y=10)`, `(x=10,y=0)`을 생각하자.

첫 점만 보고 w를 크게 키우면 첫 예측은 10에 가까워질 수 있다.

그러나 둘째 입력은 10배이므로 예측이 크게 증가해 둘째 손실이 폭발할 수 있다.

Mini-batch 한 점의 gradient는 전체 dataset gradient의 noisy estimate다.

한 step의 sample loss 감소와 전체 training loss 감소를 구분해야 한다.

## 한 데이터셋을 식과 표로 함께 읽기

01장의 배송 데이터 `x=[1,2,3] km`, `y=[2,4,5] min`을 그대로 사용한다. 여기서 **회귀(regression)**는 범주 이름이 아니라 연속적인 시간 값을 예측하는 문제다.

**선형모델(linear model)** `ŷ_i=wx_i+b`에서 `ŷ`는 y 위에 모자를 쓴 기호로 “모델이 예측한 y”를 뜻한다. 아래 첨자 i는 i번째 배송이다. `w`와 `b`는 학습 대상이고, `x_i`와 `y_i`는 데이터가 제공한다.

**예측(prediction)**은 모델이 계산한 값이다. **잔차(residual)**는 관측 정답과 예측의 차이다. 분야에 따라 `y-ŷ`를 잔차, `ŷ-y`를 오차라고 구분하기도 한다. 제곱하면 부호가 사라지지만 gradient 부호에는 정의가 중요하므로 이 장은 `e_i=ŷ_i-y_i`를 사용한다.

`w=1`, `b=1`일 때 전체 표는 다음과 같다.

| i | 거리 x_i (km) | 정답 y_i (min) | 예측 ŷ_i (min) | e_i=ŷ_i-y_i (min) | e_i² (min²) |
|---:|---:|---:|---:|---:|---:|
| 1 | 1 | 2 | 2 | 0 | 0 |
| 2 | 2 | 4 | 3 | -1 | 1 |
| 3 | 3 | 5 | 4 | -1 | 1 |

**손실(loss)**은 여러 오차를 학습이 비교할 수 있는 스칼라 하나로 모은 값이다. 평균제곱오차는 다음처럼 쓴다.

```text
MSE = (1/n) Σ(i=1..n) (ŷ_i-y_i)²
```

말로 읽으면 “각 표본의 예측에서 정답을 빼고, 제곱하고, n개를 모두 더한 뒤 n으로 나눈다”이다. 위 표에서는 `(0+1+1)/3=2/3≈0.667 min²`다.

학습 식에서는 자주 다음 목적함수를 쓴다.

```text
J(w,b) = (1/(2n)) Σ(i=1..n) (wx_i+b-y_i)²
```

MSE 앞에 `1/2`를 붙인 half-MSE다. 모든 후보 손실을 똑같이 절반으로 줄이므로 가장 작은 `w,b`의 위치는 바뀌지 않는다. 미분할 때 제곱에서 나오는 2와 약분돼 식이 간단해진다. 그러나 보고서의 MSE 0.667과 학습 code의 J 0.333을 같은 숫자라고 비교하면 안 된다.

## 두 parameter 후보를 전체 데이터로 비교하기

후보 A는 `w=1,b=1`이고 앞에서 J=`1/3≈0.333`이었다.

후보 B를 `w=1.5,b=0.5`로 두자.

```text
x=1: ŷ=2.0, error=0.0, square=0
x=2: ŷ=3.5, error=-0.5, square=0.25
x=3: ŷ=5.0, error=0.0, square=0

MSE_B = 0.25/3 ≈ 0.0833
J_B   = 0.25/6 ≈ 0.0417
```

이 training 데이터에서는 B의 평균 손실이 작다. 하지만 표본이 세 개뿐이며 실제 배송에는 교통, 날씨, 포장 종류라는 빠진 변수가 있다. Training loss가 작다는 사실은 새 배송에도 같은 오차가 나온다는 보장이 아니다.

## Weight와 bias의 단위

입력 x 단위가 km, 출력 y 단위가 min이면 `wx`가 min이 되려면 w 단위는 `min/km`여야 한다. Bias는 y와 더하므로 min이다.

`w=1.5 min/km`는 선형모델 안에서 거리 1 km 증가가 예측 시간 1.5분 증가와 연결된다는 뜻이다. 관측 연구에서 이를 “거리를 늘리면 반드시 1.5분이 원인적으로 증가한다”고 말할 수는 없다. 거리와 교통 지역이 함께 변했을 수 있기 때문이다.

## 제곱손실이 필요한 이유와 경계

오차를 그냥 더하면 `-2`와 `+2`가 0으로 상쇄된다. 절댓값이나 제곱은 크기를 남긴다. 제곱손실은 큰 오차를 더 강하게 벌주고 미분이 편리하다.

반례로 정답 `[2,4,50]`에 예측 `[2,4,5]`라면 마지막 오차 `-45`의 제곱 `2025`가 평균을 거의 지배한다. 50이 실제 중요한 극단 사례라면 강한 벌점이 적절할 수 있고, sensor 오류라면 데이터 품질을 조사해야 한다. 손실 함수만 바꿔 원인을 숨기지 않는다.

## 다중 특징과 행렬 표현

거리와 정류장 수 두 특징을 쓰면 한 배송은 `[distance,stops]` 벡터다. 가중치도 `[w_distance,w_stops]`다.

```text
x=[2 km, 3 stops]
w=[1.2 min/km, 0.5 min/stop]
b=0.4 min

ŷ = 2×1.2 + 3×0.5 + 0.4
  = 4.3 min
```

서로 다른 단위를 내적으로 더할 수 있는 이유는 각 가중치가 역단위를 포함해 모든 항을 min으로 바꾸기 때문이다. Feature scale 차이는 optimization 속도에도 영향을 주므로 뒤 장에서 학습률과 함께 본다.

## 추가 문제 5개와 전체 해설

### 문제 1

`x=4,w=2,b=-1`의 예측을 구하라.

**해설:** `ŷ=2×4-1=7`이다. x가 km이고 y가 min이면 w는 min/km, b와 결과는 min이다.

### 문제 2

정답 `[1,3]`, 예측 `[2,1]`의 MSE와 half-MSE를 구하라.

**해설:** 오차는 `[1,-2]`, 제곱은 `[1,4]`, MSE는 `5/2=2.5`다. Half-MSE는 1.25다. 최적 후보 순서는 같지만 보고 숫자는 다르다.

### 문제 3

Σ 표기 `Σ(i=1..3)e_i²`에서 e가 `[0,-1,-1]`이면?

**해설:** `0²+(-1)²+(-1)²=2`다. Σ는 세 항을 모두 더하라는 뜻이다.

### 문제 4

한 표본 loss가 줄었는데 전체 MSE가 커질 수 있는가?

**해설:** 가능하다. Parameter는 모든 표본이 공유하므로 한 점에 가까워지는 이동이 다른 점의 예측을 더 멀게 만들 수 있다. 전체 표를 다시 계산해야 한다.

### 문제 5

Training MSE 0인 모델을 완벽하다고 부를 수 있는가?

**해설:** 아니다. 적은 데이터를 암기했거나 누수가 있을 수 있다. 선택과 독립된 validation·test, 새 환경의 분포를 확인해야 한다.

## 계산을 거꾸로 점검하기

결과가 이상하면 마지막 값만 보지 않는다.

입력의 단위와 shape가 맞는지 먼저 확인한다.

중간값을 손으로 다시 계산한다.

Training 중 바뀌는 parameter와 고정된 data를 구별한다.

평가 data가 선택 과정에 들어갔는지 확인한다.

숫자의 분모와 평균 범위를 적는다.

## 실제 시스템으로 확장할 때

작은 예제는 원리를 고립시켜 보여 준다.

실제 system은 noise, queue, concurrency, finite precision을 포함한다.

Data 수집과 label 생성 지연도 성능에 포함한다.

Version, seed, split, metric 정의를 기록한다.

평균과 tail, subgroup 결과를 함께 본다.

실패와 timeout을 결과에서 지우지 않는다.

## 흔한 오해와 반례

- 선형은 입력 하나만 쓴다는 뜻이 아니다.
- Loss 0이 실제 세계의 완전한 모델을 뜻하지 않는다.
- MSE는 outlier에 민감하다.
- 상관관계로 학습한 weight를 인과효과라고 단정하지 않는다.

## 확인 문제와 해설

### 문제 1

w=2,b=1,x=3의 예측은?

**해설:** 2×3+1=7이다.

### 문제 2

오차 -3의 제곱은?

**해설:** 9다. 부호는 사라지고 크기가 남는다.

### 문제 3

Training loss가 줄면 test도 반드시 줄까?

**해설:** 아니다. 과적합이나 distribution 차이로 test loss는 커질 수 있다.
