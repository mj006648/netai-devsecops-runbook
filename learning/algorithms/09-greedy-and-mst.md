# 09. 그리디와 최소 신장 트리

[이전](08-shortest-paths.md) · [목차](README.md) · [다음](10-dynamic-programming.md)

그리디 알고리즘은 매 순간 가장 좋아 보이는 선택을 하고 그 선택을 되돌리지 않는다. 코드가 짧고 빠를 수 있지만, 눈앞의 이득이 전체 답의 이득으로 이어진다는 증명이 있을 때만 정확하다. 이 장은 활동 선택에서 그 증명을 만들고, 최소 신장 트리에서 안전한 간선을 고르는 규칙을 실제 6노드 그래프로 추적한다.

~~~mermaid
flowchart LR
    A ---|1| B
    B ---|2| C
    D ---|2| E
    C ---|3| D
    A ---|4| C
    B ---|5| D
    C ---|6| E
    D ---|7| F
    E ---|8| F
~~~

## 1. 지역 선택과 전체 최적해

**그리디(greedy)**는 아직 결정하지 않은 것 중 현재 기준으로 가장 좋은 하나를 선택하고 이전 선택을 다시 바꾸지 않는 알고리즘 방식이다. **지역 선택(local choice)**은 바로 지금 볼 수 있는 후보만 비교한 선택이다. **전역 해(global solution)**는 모든 선택이 끝난 전체 결과다.

가능한 해들 중 목표값이 가장 좋은 해를 **최적해(optimal solution)**라고 한다. 비용 문제에서는 합이 가장 작고, 활동 선택에서는 개수가 가장 많은 해가 최적이다. 그리디가 정확하려면 어떤 최적해도 그리디의 첫 선택을 포함하는 최적해로 바꿀 수 있거나, 각 단계에서 그리디가 다른 해보다 뒤처지지 않는 구조가 있어야 한다.

샘플 몇 개에서 맞았다는 사실은 증명이 아니다. 입력 전체에 대한 주장 하나는 반례 하나로 무너진다. 따라서 선택 규칙, 남은 문제의 형태, 최적성을 보존하는 이유를 함께 적어야 한다.

## 2. 동전 선택이 보여 주는 반례

동전 값 {1,3,4}로 금액 6을 만들 때 “남은 금액 이하의 가장 큰 동전을 고른다”는 그리디를 적용해 보자.

| 단계 | 남은 금액 | 고른 동전 | 새 남은 금액 | 선택 목록 |
| ---: | ---: | ---: | ---: | --- |
| 0 | 6 | 없음 | 6 | [] |
| 1 | 6 | 4 | 2 | [4] |
| 2 | 2 | 1 | 1 | [4,1] |
| 3 | 1 | 1 | 0 | [4,1,1] |

그리디는 세 동전을 쓴다. 그러나 3+3은 두 동전이므로 더 좋다. 첫 4를 선택한 뒤에는 최적해 3+3으로 바꿀 수 없다. {1,5,10,25} 같은 특정 동전 체계에서 큰 동전 우선 규칙이 맞는 많은 금액이 있어도 모든 동전 집합에 대한 증명이 되지 않는다.

## 3. 활동 선택과 완전한 교환 증명

활동은 시작 시각과 종료 시각을 가진다. 한 사람이 겹치지 않게 수행할 수 있는 활동 수를 최대화한다고 하자. 종료 시각과 다음 시작 시각이 같으면 이어서 수행할 수 있다고 정한다.

| 활동 | 시작 | 종료 |
| --- | ---: | ---: |
| A | 1 | 4 |
| B | 3 | 5 |
| C | 0 | 6 |
| D | 5 | 7 |
| E | 3 | 9 |
| F | 5 | 9 |
| G | 8 | 10 |
| H | 9 | 11 |

그리디 규칙은 “현재 선택들과 겹치지 않는 활동 중 가장 일찍 끝나는 활동을 고른다”이다. 종료 시각순으로 보고 추적하면 다음과 같다.

| 검사 | 현재 마지막 종료 | 결정 | 이유 | 선택 |
| --- | ---: | --- | --- | --- |
| A(1,4) | 없음 | 선택 | 첫 활동 중 가장 일찍 종료 | A |
| B(3,5) | 4 | 제외 | 3 < 4라 겹침 | A |
| C(0,6) | 4 | 제외 | 0 < 4 | A |
| D(5,7) | 4 | 선택 | 5 ≥ 4 | A,D |
| E(3,9) | 7 | 제외 | 3 < 7 | A,D |
| F(5,9) | 7 | 제외 | 5 < 7 | A,D |
| G(8,10) | 7 | 선택 | 8 ≥ 7 | A,D,G |
| H(9,11) | 10 | 제외 | 9 < 10 | A,D,G |

결과는 세 활동 A,D,G다.

**교환 논증(exchange argument)**은 임의의 최적해 일부를 그리디 선택으로 바꿔도 최적성을 잃지 않음을 보이는 증명 방식이다. 첫 활동 중 가장 일찍 끝나는 활동을 g라 하고, 어떤 최적해 O의 첫 활동을 o라 하자. g의 종료 시각은 o보다 늦지 않다. O에서 o를 g로 바꾸면 o 뒤 활동들은 o가 끝난 뒤 시작하므로 더 일찍 끝나는 g와도 겹치지 않는다. 활동 수는 그대로라 g를 포함하는 최적해가 존재한다.

g 뒤에 시작할 수 있는 활동만 남기면 원래 문제와 같은 모양의 더 작은 활동 선택 문제가 된다. 남은 문제에서도 가장 일찍 끝나는 활동을 같은 교환 논증으로 포함시킬 수 있다. 이를 반복하면 그리디가 고른 모든 활동을 포함하는 최적해가 있으므로 결과가 최적이다. “짧은 활동”이나 “가장 일찍 시작하는 활동”은 종료 후 남기는 시간이 가장 크다는 교환 근거가 없어 같은 증명을 쓸 수 없다.

~~~python
def select_activities(activities):
    ordered = sorted(activities, key=lambda item: item[2])
    selected = []
    last_end = None

    for name, start, end in ordered:
        if last_end is None or start >= last_end:
            selected.append((name, start, end))
            last_end = end

    return selected
~~~

첫 줄은 종료 시각으로 정렬한다. 반복은 이미 고른 마지막 종료 이후에 시작하는 활동만 선택한다. 정렬 O(n log n), 한 번 훑기 O(n)이므로 전체 O(n log n)이다. 입력이 이미 종료 시각순이면 훑기만 O(n)이다.

활동 선택 증명을 일반화하면 그리디 검증 순서는 다음과 같다. 먼저 지역 선택을 정확히 정의한다. 다음으로 임의의 최적해를 그 선택을 포함하도록 교환해도 목적값이 나빠지지 않음을 보인다. 마지막으로 선택 뒤 남은 입력이 원래와 같은 형태의 더 작은 문제인지 확인한다. 이 세 단계 중 하나가 빠지면 “좋아 보이는 규칙”인 휴리스틱일 수는 있어도 최적 알고리즘이라고 결론 낼 수 없다.

**휴리스틱(heuristic)**은 빠르게 괜찮은 답을 찾도록 만든 경험적 규칙이며 항상 최적이라는 증명을 요구하지 않는다. 큰 실제 문제에서 유용할 수 있지만 출력 계약이 다르다. 그리디 알고리즘도 증명이 없으면 휴리스틱으로만 취급해야 한다.

## 4. 사이클, 신장 트리, MST

무방향 그래프에서 **사이클(cycle)**은 간선을 따라 출발 정점으로 되돌아오는 비어 있지 않은 경로다. A-B, B-C, C-A 세 간선은 사이클을 만든다.

**신장 트리(spanning tree)**는 연결된 무방향 그래프의 모든 정점을 포함하고, 모든 정점을 서로 연결하며, 사이클이 없는 간선 부분집합이다. 정점 V개의 트리는 정확히 V-1개 간선을 가진다. 더 적으면 연결할 수 없고, 연결된 상태에서 더 넣으면 사이클이 생긴다.

간선마다 비용이 있을 때 가중치 합이 가장 작은 신장 트리를 **최소 신장 트리(MST, Minimum Spanning Tree)**라고 한다. 목표는 선택한 전체 간선 합을 최소화하는 것이다. 한 source에서 각 정점까지 경로 비용을 최소화하는 최단 경로 트리와 목적이 다르다.

이 장의 그래프는 정점 A,B,C,D,E,F 여섯 개와 간선 아홉 개다. 연결되어 있으므로 MST가 존재하고, 결과는 간선 다섯 개를 가져야 한다.

## 5. 절단과 안전한 간선

**절단(cut)**은 정점 집합을 비어 있지 않은 두 그룹으로 나누는 것이다. 한 끝이 한 그룹, 다른 끝이 다른 그룹에 있는 간선이 절단을 가로지른다. **절단 성질(cut property)**은 현재 선택한 MST 일부와 모순되지 않는 절단에서, 그 절단을 가로지르는 최소 가중치 간선을 어떤 MST에 안전하게 포함할 수 있다는 성질이다.

왜 안전한지 교환으로 보자. 최소 교차 간선 e를 포함하지 않는 MST T가 있다고 하자. e를 T에 추가하면 사이클 하나가 생긴다. 그 사이클은 절단을 나갔다가 돌아와야 하므로 e 외에 절단을 가로지르는 간선 f가 있다. e가 최소이므로 weight(e) ≤ weight(f)다. T에서 f를 빼고 e를 넣으면 다시 신장 트리이며 총비용은 커지지 않는다. 따라서 e를 포함하는 MST가 존재한다.

이 증명은 “그래프 전체에서 가장 짧은 간선이면 무조건 고른다”가 아니다. 현재 선택과 충돌하지 않는 절단을 가로지르는 안전한 최소 간선이라는 조건이 필요하다.

## 6. 서로소 집합 자료구조

Kruskal은 두 정점이 현재 선택 간선으로 이미 연결됐는지 자주 묻는다. **서로소 집합 자료구조(DSU, Disjoint Set Union)**는 겹치지 않는 여러 그룹을 메모리에 유지한다. Union–Find라고도 한다.

- find(x)는 x가 속한 그룹의 대표 정점을 돌려준다.
- union(a,b)는 서로 다른 두 그룹을 하나로 합친다.
- find(a) == find(b)이면 이미 경로가 있어 a-b 간선을 더할 때 사이클이 생긴다.

~~~python
class DSU:
    def __init__(self, nodes):
        self.parent = {node: node for node in nodes}
        self.size = {node: 1 for node in nodes}

    def find(self, node):
        if self.parent[node] != node:
            self.parent[node] = self.find(self.parent[node])
        return self.parent[node]

    def union(self, first, second):
        root_a = self.find(first)
        root_b = self.find(second)
        if root_a == root_b:
            return False

        if self.size[root_a] < self.size[root_b]:
            root_a, root_b = root_b, root_a

        self.parent[root_b] = root_a
        self.size[root_a] += self.size[root_b]
        return True
~~~

parent는 각 정점에서 대표로 가는 연결을 저장한다. find의 경로 압축은 중간 정점이 대표를 직접 가리키게 한다. union은 작은 그룹의 대표를 큰 그룹 대표 아래 붙인다. 이 두 최적화를 쓰면 연속 연산의 분할 상환 비용은 매우 작고 역 아커만 함수로 표현된다. 핵심 의미는 대표가 같은지 여부다.

DSU 내부 parent 값은 합칠 때 어느 대표를 위로 두는지에 따라 달라질 수 있다. 중요한 불변식은 같은 요소의 정점들이 find에서 같은 대표를 얻는다는 것이다. 크기 기준 합치기에서 동률이면 첫 대표를 유지한다고 가정하면 선택 간선 뒤의 한 가능한 parent 변화는 다음과 같다.

| union | 바뀐 parent | 대표별 정점 |
| --- | --- | --- |
| 초기 | 모두 자기 자신 | A / B / C / D / E / F |
| A,B | parent[B]=A | A:{A,B}, C, D, E, F |
| B,C | find(B)=A, parent[C]=A | A:{A,B,C}, D, E, F |
| D,E | parent[E]=D | A:{A,B,C}, D:{D,E}, F |
| C,D | find(C)=A, parent[D]=A | A:{A,B,C,D,E}, F |
| D,F | find(D)=A, parent[F]=A | A:{A,B,C,D,E,F} |

E가 한동안 D를 가리켜도 find(E)는 D를 거쳐 A에 도착하며 경로 압축 뒤 A를 직접 가리킬 수 있다. parent 배열의 모양은 MST 간선 자체가 아니다. DSU는 연결 요소 판정용 보조 객체이고, 선택한 실제 간선은 chosen 목록에 따로 저장한다.

## 7. Kruskal과 6노드 9간선 전체 추적

**Kruskal 알고리즘**은 모든 간선을 가중치 오름차순으로 정렬하고, 양끝이 서로 다른 DSU 그룹에 있을 때만 선택한다. 선택하면 union으로 그룹을 합친다.

정렬된 간선은 AB1, BC2, DE2, CD3, AC4, BD5, CE6, DF7, EF8이다. 같은 가중치 BC2와 DE2의 순서는 바뀌어도 이 그래프의 총 MST 비용은 같다.

| 순서 | 간선 | 처리 전 요소 | 판단 | 처리 후 요소 | 선택 합 |
| ---: | --- | --- | --- | --- | ---: |
| 1 | A-B=1 | {A},{B},{C},{D},{E},{F} | 다름, 선택 | {A,B},{C},{D},{E},{F} | 1 |
| 2 | B-C=2 | {A,B},{C},{D},{E},{F} | 다름, 선택 | {A,B,C},{D},{E},{F} | 3 |
| 3 | D-E=2 | {A,B,C},{D},{E},{F} | 다름, 선택 | {A,B,C},{D,E},{F} | 5 |
| 4 | C-D=3 | {A,B,C},{D,E},{F} | 다름, 선택 | {A,B,C,D,E},{F} | 8 |
| 5 | A-C=4 | {A,B,C,D,E},{F} | 같은 요소, 사이클이라 제외 | 변화 없음 | 8 |
| 6 | B-D=5 | {A,B,C,D,E},{F} | 같은 요소, 제외 | 변화 없음 | 8 |
| 7 | C-E=6 | {A,B,C,D,E},{F} | 같은 요소, 제외 | 변화 없음 | 8 |
| 8 | D-F=7 | {A,B,C,D,E},{F} | 다름, 선택 | {A,B,C,D,E,F} | 15 |
| 9 | E-F=8 | 이미 모두 연결 | 같은 요소, 제외 또는 검사 생략 | 변화 없음 | 15 |

선택 간선은 AB, BC, DE, CD, DF 다섯 개이고 합은 1+2+2+3+7=15다. A-C를 넣으면 이미 A-B-C 경로가 있어 A-B-C-A 사이클이 생긴다. 원본 그래프에서 제외 간선을 삭제하는 것이 아니라 MST 결과 집합에 넣지 않는 것이다.

~~~python
def kruskal(nodes, edges):
    dsu = DSU(nodes)
    chosen = []
    total = 0

    for weight, first, second in sorted(edges):
        if dsu.union(first, second):
            chosen.append((first, second, weight))
            total += weight
            if len(chosen) == len(nodes) - 1:
                break

    if len(chosen) != len(nodes) - 1:
        raise ValueError("graph is disconnected")
    return chosen, total
~~~

정렬이 O(E log E)를 쓰고 DSU 연산은 거의 상수에 가까운 분할 상환 비용이므로 전체는 O(E log E)가 지배한다. V-1개를 못 고르고 간선이 끝나면 그래프가 연결되지 않아 하나의 신장 트리가 없다. 그때 중간 결과는 각 연결 요소의 최소 신장 숲이다.

간선 정렬 뒤 각 간선에서 find를 최대 몇 번 수행하고 선택 간선에서 union을 한 번 한다. 경로 압축과 크기 합치기를 쓴 E번 규모의 DSU 연산은 O(E α(V))로 표현하며, α는 실제 크기에서 매우 천천히 증가한다. 따라서 비교 정렬 O(E log E)가 전체 시간을 지배한다. 간선 목록, DSU 상태, 선택 결과를 저장하는 공간은 O(V+E)다.

## 8. Prim: 현재 트리에서 바깥으로 넓히기

**Prim 알고리즘**은 시작 정점 하나에서 출발해 현재 트리와 바깥 정점을 잇는 간선 중 가장 싼 것을 반복 선택한다. 경계를 가로지르는 후보를 최소 우선순위 큐에 둔다.

A에서 시작하면 AB1을 선택해 {A,B}, 다음 BC2로 {A,B,C}, 다음 CD3으로 D를 붙인다. D가 들어오면 새 경계 간선 DE2가 생겨 기존 CE6보다 먼저 선택된다. 마지막 DF7과 EF8 중 DF7로 F를 붙인다. 결과는 Kruskal과 같은 다섯 간선, 비용 15다.

Prim의 각 선택은 “현재 트리 정점 집합과 나머지”라는 절단의 최소 교차 간선이라 절단 성질로 안전하다. Kruskal은 그래프 전체 간선을 정렬하고 여러 요소를 합치며, Prim은 하나의 트리와 바깥 사이 경계를 관리한다. 인접 목록과 이진 힙에서는 O(E log V)로 설명한다.

그래프가 연결되지 않았다면 한 시작점 Prim은 그 요소만 방문한다. 모든 정점을 포함해야 한다는 신장 트리 명세를 만족하지 않으므로 방문 정점 수를 확인해야 한다.

Prim의 우선순위 큐 변화도 끝까지 추적해 보자. “안쪽”은 이미 트리에 든 정점이다.

| 단계 | 꺼낸 간선 | 판단 | 안쪽 정점 | 새로 추가한 경계 후보 |
| ---: | --- | --- | --- | --- |
| 0 | 없음 | A에서 시작 | {A} | AB1, AC4 |
| 1 | AB1 | B가 밖이라 선택 | {A,B} | BC2, BD5 |
| 2 | BC2 | C가 밖이라 선택 | {A,B,C} | CD3, CE6 |
| 3 | CD3 | D가 밖이라 선택 | {A,B,C,D} | DE2, DF7 |
| 4 | DE2 | E가 밖이라 선택 | {A,B,C,D,E} | EF8 |
| 5 | AC4 | 양끝이 안쪽, 건너뜀 | 변화 없음 | 없음 |
| 6 | BD5 | 양끝이 안쪽, 건너뜀 | 변화 없음 | 없음 |
| 7 | CE6 | 양끝이 안쪽, 건너뜀 | 변화 없음 | 없음 |
| 8 | DF7 | F가 밖이라 선택 | 모든 정점 | 종료 |

우선순위 큐에는 과거 경계였지만 이제 양끝이 모두 안쪽인 stale 간선이 남을 수 있다. 꺼냈을 때 바깥 정점을 새로 연결하지 않으면 버린다. 선택 합은 1+2+3+2+7=15다. Prim은 간선을 발견한 순서가 아니라 현재 큐 전체의 최소 가중치를 고르므로 D를 넣은 뒤 발견한 DE2가 먼저 발견된 AC4보다 앞선다.

## 9. 같은 가중치와 여러 MST

절단의 최소 간선이 여러 개면 어느 하나를 안전하게 선택할 수 있지만 결과 트리는 달라질 수 있다. 같은 총비용의 MST가 여러 개 존재할 수 있다. 테스트는 특정 간선 목록 하나만 강제하기보다 모든 정점을 연결하는지, 사이클이 없는지, 간선 수 V-1인지, 총비용이 최소값인지 검사해야 한다.

모든 간선 가중치가 서로 다르면 MST는 유일하다. 그러나 같은 가중치가 있다고 반드시 여러 MST인 것은 아니다. 구조상 선택 여지가 없으면 여전히 하나일 수 있다.

## 10. MST와 최단 경로의 차이

MST는 전체 연결 비용 합을 줄인다. 최단 경로 트리는 한 source에서 각 정점까지의 경로 비용을 원래 그래프의 최단 거리와 같게 만든다. MST 안의 두 정점 경로가 원래 그래프의 최단일 필요는 없다.

예를 들어 A-B=2, B-C=2, A-C=3이면 MST는 A-B와 B-C를 골라 합 4다. MST 안에서 A에서 C까지는 비용 4지만 원래 그래프의 직접 A-C 비용 3이 더 짧다. 목표 함수를 섞으면 올바른 MST를 잘못 평가하게 된다.

## 11. 확인 문제와 자세한 풀이

### 문제 1. 동전 그리디 반례

동전 {1,3,4}로 6을 만드는 큰 동전 우선 결과와 최적해를 비교하고, 이 반례가 무엇을 부정하는지 설명하라.

**풀이.** 그리디는 4를 고르고 남은 2를 1과 1로 만들어 [4,1,1], 세 개다. [3,3]은 두 개라 더 적다. 이 한 입력은 “모든 동전 체계와 금액에서 큰 동전 우선이 최적”이라는 보편 주장을 부정한다. 특정 체계 {1,5,10,25}의 정확성이나 다른 그리디 문제까지 모두 부정하는 것은 아니다. 각 문제 구조마다 별도 증명이 필요하다.

### 문제 2. 활동 선택의 첫 교환

최적해의 첫 활동이 B(3,5)이고 그리디 첫 활동이 A(1,4)라면 B를 A로 바꿔도 뒤 활동이 가능한 이유를 설명하라.

**풀이.** A의 종료 4는 B의 종료 5보다 이르다. 원래 최적해에서 B 뒤에 오는 모든 활동은 시작이 5 이상이므로 4 이상이기도 하다. B를 A로 교환해도 뒤 활동과 겹치지 않고 활동 수는 그대로다. 따라서 A를 포함하는 최적해가 있다. 이 교환 뒤 남은 문제도 A 종료 이후 활동을 최대 선택하는 같은 형태라 논증을 반복할 수 있다.

### 문제 3. Kruskal의 한 간선

공통 그래프에서 AB, BC, DE, CD를 고른 뒤 AC4를 왜 제외하고 DF7은 왜 선택하는가?

**풀이.** 네 간선 뒤 요소는 {A,B,C,D,E}와 {F}다. A와 C는 같은 요소에 있어 이미 A-B-C 경로가 있다. AC를 추가하면 사이클이므로 제외한다. D는 큰 요소, F는 다른 요소라 DF는 사이클을 만들지 않고 두 요소를 연결한다. 남은 절단 교차 간선 DF7과 EF8 중 DF가 더 가벼워 안전하며 선택 뒤 모든 정점이 연결된다.

### 문제 4. 연결되지 않은 입력

정점 {A,B,C,D}와 간선 AB1, CD2만 있을 때 Kruskal 결과와 오류 조건을 설명하라.

**풀이.** AB와 CD는 각각 다른 정점을 연결하므로 둘 다 선택된다. 결과는 {A,B}와 {C,D} 두 트리인 최소 신장 숲이다. 정점 4개의 신장 트리는 간선 3개가 필요한데 후보가 끝나도 두 개뿐이다. 하나의 MST를 요구하는 함수라면 disconnected 오류를 내야 한다. 숲이 명세라면 두 요소 결과를 정상 반환할 수 있다.

### 문제 5. 절단 교환 증명

어떤 절단의 최소 교차 간선 e가 기존 MST T에 없을 때, e를 넣고 무엇을 빼야 하며 비용은 왜 늘지 않는가?

**풀이.** T에 e를 더하면 유일한 사이클이 생긴다. 사이클은 절단의 한쪽에서 다른 쪽으로 e를 통해 갔으므로 다시 돌아오는 또 다른 교차 간선 f를 포함한다. e가 절단 최소라 weight(e) ≤ weight(f)다. f를 빼면 연결은 유지되고 사이클은 사라져 다시 신장 트리다. 총비용은 e-f만큼 변해 증가하지 않는다. 따라서 e를 포함하는 최적 트리가 존재한다.

### 문제 6. Prim의 후보 갱신

공통 그래프에서 A,B,C,D까지 Prim 트리에 들어온 순간 다음에 DE2가 선택되는 이유를 설명하라.

**풀이.** D가 들어오기 전 경계 후보에는 C-E6 등이 있다. D를 넣으면 D-E2와 D-F7이 새로 경계를 가로지른다. 우선순위 큐는 발견 시각이 아니라 가중치가 가장 작은 DE2를 먼저 꺼낸다. 현재 집합과 바깥의 절단에서 DE가 최소이므로 안전하다. 단순 FIFO 큐를 쓰면 CE6을 먼저 고를 수 있어 Prim 규칙과 비용 보장을 잃는다.

### 문제 7. MST 검증

정점 6개 결과 간선이 5개이고 총비용 15라고만 알면 MST라고 확정할 수 있는가?

**풀이.** 확정할 수 없다. 간선 5개가 사이클을 만들면 어떤 정점이 분리될 수 있고, 연결된 트리여도 더 싼 다른 트리가 있을 수 있다. 먼저 모든 정점을 포함하고 연결되며 사이클이 없는지 검사한다. 그다음 Kruskal의 정렬·DSU 선택이나 절단 성질 같은 최적성 근거로 비용 15가 최소임을 보여야 한다. 간선 수와 합은 필요한 증거 일부일 뿐이다.

## 12. 구현 점검표

그리디 규칙을 한 문장으로 적고 그 선택을 포함하는 최적해가 존재한다는 교환 또는 절단 증명을 만든다. MST 입력은 무방향·가중·연결 그래프인지 확인한다. Kruskal은 정렬 뒤 대표가 다른 간선만 선택하고 선택한 뒤에만 union한다. Prim은 현재 트리와 바깥을 잇는 간선만 후보로 둔다. 중복 가중치, 연결되지 않은 그래프, 한 정점, 평행 간선에서 명세를 확인한다.

## 참고

활동 선택과 MST의 정확성은 예제 결과가 아니라 교환 논증과 절단 성질에 근거한다. 이 장의 DSU는 경로 압축과 크기 기준 합치기를 사용한다.
