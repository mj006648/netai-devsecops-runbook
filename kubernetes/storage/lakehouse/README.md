# Apache Iceberg와 Open Table Format 논문 읽기

작성·문헌 확인일: **2026-09-16**

Apache Iceberg, Delta Lake, Hudi를 이해하고 NetAI의 데이터 플랫폼 설계에 연결하기 위한 문헌 연구 노트다. **실제 클러스터에서 재현한 장애 기록이나 도입 완료 보고서가 아니다.** 논문의 실험 결과, 공식 규격, 이 문서의 해석과 실험 제안을 구분한다.

## 선정 원칙

- 최근 범위는 **2024–2026년**으로 잡고, 비교 기준이 되는 2023년 논문과 2020년 원전은 별도로 포함한다.
- 논문 제목의 관련성만으로 선정하지 않는다. 출판사·학회 원문에서 게재 정보와 기여를 확인한다.
- **SCI/SCIE 등재, 학술지 게재, 주요 학회 채택은 서로 다른 정보다.** PVLDB와 *The VLDB Journal*도 서로 다른 간행물이다.
- DOI가 있다고 SCIE 논문인 것은 아니다. 색인 상태를 확인하지 못한 간행물은 확인 범위를 그대로 표시한다.
- 소프트웨어 버전·워크로드가 다른 결과를 합쳐 포맷의 절대 성능 순위를 만들지 않는다.
- 원문 전체를 번역하거나 그림을 복제하지 않고, 핵심을 요약한 뒤 별도의 비평·예제로 설명한다.

## 이 노트에서 사용하는 표시

| 표시 | 의미 |
| --- | --- |
| **원문 근거** | 링크된 논문이나 공식 문서에서 확인한 내용 |
| **해석** | 여러 근거를 연결한 이 노트의 판단 |
| **제안** | 아직 NetAI 환경에서 수행하지 않은 설계·실험 |
| **미확인** | 전문, 색인 또는 재현 조건을 충분히 검증하지 못한 항목 |

연구 프로토타입의 기능을 Apache Iceberg의 기본 제공 기능으로 옮겨 적지 않는다. `latest` 공식 문서 링크는 변경되므로 실제 실험에서는 릴리스 번호와 컨테이너 이미지 digest까지 고정한다.
