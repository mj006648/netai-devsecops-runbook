## 3. 외부 PSU 구매 검토 — 창현

### 현재 증상과 기존 구성

- edgebox3/4는 전원 문제로 복구가 필요한 상태다.
- 외부 PSU LED가 꺼지거나 매우 어둡고 불안정하며, 서버가 약한 전원 표시만 보이고 boot되지 않는 증상이 보고됐다.
- 서버에서 분리한 외부 PSU도 불안정했다는 보고가 있다. **추정:** 외부 PSU 불량 가능성이 높지만, DC 배선·단자·내부 PSU까지의 원인은 확정되지 않았다.
- 기존 구성은 `AC → 외부 S-1200-48 → 서버 내부 DC PSU → 서버`다.
- 기존 장애 조사: [SYS-210P DC PSU 기록](../hardware/power/supermicro-sys-210p-dc-psu-2026-07-01.md).

### 기존 외부 PSU 라벨에서 확인한 사양

| 항목 | 사용자 확인 내용 |
| --- | --- |
| 모델 | `S-1200-48` |
| INPUT | `AC 110/220V ±15%`, `50/60Hz` |
| OUTPUT | `+48V DC`, `25A` |
| 정격 출력 계산 | `48V × 25A = 1200W` |
| 입력 선택 스위치 | `115V / 230V` 선택형, 현재 **230V** 위치 |
| 제조사 / 예전 구매처 | 미확인 |

구매 대상은 **48V·25A·1200W 외부 AC-to-DC SMPS**다. `S-1200-48`이라는 이름을 여러 업체가 사용하므로, 같은 모델명·출력 사양만으로 기존 제조사와 동일한 제품이라고 확정하지 않는다.

### Supermicro 답변에서 확인된 내용

사용자가 제공한 **2026-07-03 Supermicro Support 답변** 기준:

- `SYS-210P-FRDN6T`의 AC PSU 전환은 지원된다.
- 호환 AC PSU는 **`PWS-606P-1R`, 600W**다.
- 추가 power distribution board·cage·conversion kit 등의 부품은 필요 없다는 답변이다.
- 전환한다면 **서버 전원을 끈 상태에서 두 내부 PSU를 모두 AC 모델로 교체**해야 한다.
- third-party 외부 S-1200-48 대체 제품의 허용 여부나 요구 전기 사양에는 별도 확인 답변이 없었다. 외부 판매 후보를 Supermicro 승인 제품으로 해석하지 않는다.

현재 검토 방향은 **기존 DC 구성을 유지하면서 외부 PSU를 교체하는 것**이다. AC 전환 답변은 대안으로 보관한다. 내부 `PWS-606P-1R` 구매 정보는 [Supermicro eStore](https://store.supermicro.com/600w-1u-pws-606p-1r.html)에 있다.

### 구매 후보 확정 전 확인

1. 기존 제품의 제조사 로고·전체 라벨·치수·단자 배열과 판매 제품을 대조한다.
2. 실물 출고 사양이 **AC 220/230V 대응, DC 48V·25A·1200W**인지 판매자에게 확인할 질문을 정리한다.
3. 기존 내부 PSU의 **-48V 입력**과 외부 SMPS의 **+48V 출력** 표기는 기준점이 다르다. 기존 DC polarity·접지·배선 방식과 출력 절연 조건을 확인한다. 라벨 부호만 보고 단자를 바꾸거나 접지를 새로 연결하지 않는다.
4. 고장난 외부 PSU 개수·노드별 연결 방식·견적·납기·보증 조건을 확인하고 교수님께 구매안을 공유한다. 고장 노드 두 대라는 이유만으로 필요한 외부 PSU 수량을 두 개로 확정하지 않는다.

**현재 결론:** 사양이 맞는 판매 후보는 찾았지만, 기존 제조사와 동일한 교체 제품은 아직 확정하지 않았다.

## 4. T4 GPU 이전 검토 — 창현

목표는 **edgebox1·2·3·4에 있던 T4를 sv4000-1로 이전하는 것**이다. 노드별 실제 카드 수량·상태·브래킷은 재확인 대상이며, 각 노드 한 장이라는 조건이면 총 네 장이다.

### T4의 PCIe 및 장착 조건

| 항목 | 조사 내용 |
| --- | --- |
| PCIe 규격 | **PCIe Gen3**, **x16 및 x8 연결 지원**: Gen3는 세대, x16/x8은 레인 수 |
| 카드 크기 | Low-profile / half-height, half-length, single-slot |
| 정격 전력 | **70W** maximum board power |
| 냉각 | **Passive heatsink**: 서버의 강제 airflow 필요 |
| 상위 세대 슬롯 | Gen4/Gen5 슬롯에서도 공통 규격으로 연결하는 것이 원칙. T4의 최대 링크는 Gen3이며 슬롯의 물리 크기·실제 레인·전원·OEM 지원은 별도 확인 |

T4 규격 근거: [NVIDIA T4 Product Brief](https://www.nvidia.com/content/dam/en-zz/Solutions/Data-Center/tesla-t4/t4-tensor-core-product-brief.pdf), Overview 및 Product Specifications. PCIe 상위 세대와의 연결 원칙은 [ASUS ESC4000A-E12 datasheet](https://dlcdnets.asus.com/pub/ASUS/server/ESC4000A-E12/Datasheet/DataSheet_ESC4000A-E12_20221020.pdf)의 backward compatibility 설명을 참고한다.

### sv4000-1 기존 기록과 조건부 판단

[기존 장비 실측 기록](../hardware/inventory/twinx-gpu-node-expansion-2026-09-23.md#sv4000-1)은 **2026-10-01 05:22 UTC 재확인** 기준이다. 이번 회의록 작성 중 서버에 재접속하거나 GPU를 이동한 결과는 아니다.

- 서버: **ASUS ESC4000A-E12**, EPYC 9124.
- 기존 큰 GPU 베이: **Gen5 x16 이중 폭 베이 4개**.
- 기록된 GPU: **RTX A6000×2 + A100 PCIe 40GB×1**.
- NIC: ConnectX-5 Ex 100G 한 장. 작은 NIC/RAID 라이저 자리는 GPU 베이와 구분한다.
- PSU 기록: 2600W×2. 1+1 중복 전원에서는 두 모듈 용량을 단순 합산하지 않는다.

**추정:** 회의안대로 A6000 두 장을 RM352로 보내고 sv4000-2의 A100 한 장을 추가로 받으며 기존 A100을 유지한다면, sv4000-1에는 **A100 두 장**이 남는다. 현재의 네 GPU 베이 구성만 기준으로 하면 T4 두 장을 추가할 공간이 우선 후보이며, T4 네 장 동시 이전은 확정할 수 없다.

ASUS의 다른 지원 구성에는 **single-slot GPU 8개 / Gen5 x8 link**가 명시돼 있다. 따라서 T4 네 장의 장착을 불가능하다고 단정하지도 않는다. **현재 설치된 GPU 라이저, 8개 single-slot 구성에 필요한 부품, A100 두 장과 T4 네 장 혼합 지원 여부**를 OEM과 대조해야 한다. x16 형상의 슬롯도 실제 연결은 x8일 수 있다. [ASUS 공식 슬롯 사양](https://dlcdnets.asus.com/pub/ASUS/server/ESC4000A-E12/Datasheet/DataSheet_ESC4000A-E12_20221020.pdf#page=2).

**추정:** A100 두 장을 유지하고 나머지 두 GPU 베이를 각각 single-slot 카드 두 장용으로 구성할 수 있다면 T4 네 장의 공간을 확보할 가능성이 있다. 이는 검토할 배치안이며, 현재 라이저가 그런 혼합 구성과 레인 분할을 지원한다는 실측은 없다. T4 자체는 Gen3 x8 연결도 지원하므로 x8이라는 이유만으로 배제하지 않는다.

2026-10-06 조회한 [ASUS GPU Compatibility List](https://servers.asus.com/support/gpu)에서는 **ESC4000A-E12 + T4** 조합의 공식 지원을 확인하지 못했다. 다른 모델인 ESC4000A-E10의 T4 지원을 E12에 그대로 적용하지 않는다.

### 현장 및 OEM 확인 항목

1. edgebox1~4의 실제 T4 수량·카드 상태·브래킷 형태를 확인한다. 전원 고장 노드는 OS 조회만으로 GPU 상태를 확인할 수 없다.
2. sv4000-1의 현재 GPU와 NIC를 다시 조회해 기존 A100의 유지 여부를 결정한다.
3. GPU 라이저 P/N·현재 커넥터 수·실물 슬롯 위치·single-slot 추가 구성 여부를 확인한다. 펌웨어 `PCIE` 번호만으로 물리 슬롯을 확정하지 않는다.
4. ASUS에 **T4 지원 여부, A100×2+T4×4 혼합 구성, 필요한 라이저·브래킷·air duct, 슬롯별 70W 공급 및 fan profile**을 확인한다.
5. x8 연결 후보는 T4가 실제로 협상하는 폭과 워크로드 영향을 확인한다. **Gen3 x8은 지원되는 연결이지만 Gen3 x16의 절반 폭**이다. 라이저·BIOS·driver 변경 없이 조사 결과부터 정리한다.
6. 전체 GPU 전력·CPU·NIC·디스크·팬 및 한 PSU 장애 시 전력 여유를 함께 검토한다. 네 T4의 정격 합 `4×70W=280W`는 서버 전체 전력 예산이 아니다.

### 서버에서 확인할 read-only 명령

아래 명령은 대상 서버에서 실행할 조회 예시다. 아직 이 회의록을 위한 새 실측 출력은 수집하지 않았다.

```bash
# 서버 모델·보드 모델·슬롯 펌웨어 정보: serial number는 문서에 옮기지 않는다.
sudo dmidecode -s system-manufacturer
sudo dmidecode -s system-product-name
sudo dmidecode -s baseboard-product-name
sudo dmidecode -t slot

# 장착 GPU 및 PCIe topology
nvidia-smi -L
nvidia-smi -q -d PCI
nvidia-smi topo -m
lspci -Dnn
lspci -tv

# lspci에서 확인한 실제 GPU BDF를 사용한다.
# LnkCap은 지원 능력, LnkSta는 조회 당시 협상 상태다.
sudo lspci -s '<GPU_BDF>' -vv
```

유휴 GPU의 Gen1/Gen2 보고는 절전 상태일 수 있다. 이를 곧바로 슬롯 세대나 고장으로 해석하지 않는다. OS에 장치가 보이는 것만으로 브래킷·패시브 냉각·OEM 호환성이 증명되지는 않는다.

**현재 결론:** PCIe 세대 차이 자체는 이전을 막는 근거가 아니다. 실제 이전 가능 수량은 **라이저 구성, 기존 A100 처리, 혼합 구성 지원, 냉각** 확인 후 결정한다.

### 이동 전에 풀어야 할 겹침과 선후 관계

- **A5 U21~U24:** GIGABYTE GPU 이동안과 RNGD NPU 4EA 이동안이 같은 목적지를 가리킨다. 대안인지 동일 노드 통합인지 확인한다.
- **A5 U21:** l40의 현재 위치 표기와 위 목적지의 경계가 겹친다. U 표기가 연속 범위라면 l40를 A3로 먼저 옮겨야 하므로 실제 점유 범위와 이동 순서를 확인한다.
- **A4 U20~U21:** sv4000#2 이동안과 PRO6000 2EA 이동안의 목적지가 같다. 현재 ARM server의 출발 자리이기도 하므로, 장비 단위·통합 여부·이동 순서를 확인한다.
- **A4 U35~U38:** sv4000 두 노드를 먼저 옮겨야 SYS#3/#4의 목적지가 비워진다.
- **A3 U12~U16:** U.2와 E1s 이동 후 신규 HDD#2 설치 위치를 확보한다.
- 원문의 `U26,U29` 같은 표기가 연속 점유 범위의 양 끝인지 별도 위치인지는 랙 배치도와 대조한다. 여러 가속기를 한 섀시에 합치는 경우에도 PSU·냉각·PCIe 라이저 조건을 별도로 확인한다.
